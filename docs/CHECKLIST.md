## Observações importantes

- A Alpha Log é fictícia, portanto nenhuma métrica ilustrativa deve ser comunicada como dado real.
- Uma landing page não exige, por si só, backend. Para a **captação comercial real**, é necessário configurar um número de WhatsApp ou uma integração com CRM, dados não fornecidos.
- Os serviços respeitam as exclusões do briefing (sem cargas perigosas, químicas controladas e hospitalares críticas).
